## Fiche de session

| Élément | Valeur |
|---|---|
| Nuit | Du 9 au 10 août 2026 |
| Objectif principal | Valider l’installation complète |
| Monture | Sky-Watcher EQ6-R Pro |
| Instrument principal | C8 EdgeHD + Canon EOS 1200D |
| Guidage | EvoGuide 50ED + ASI120MM-S |
| Logiciels | KStars, Ekos, INDI et StellarSolver |

## Objectif à atteindre

- mettre en service l’installation complète ;
- connecter tous les équipements dans INDI ;
- créer les deux trains optiques dans Ekos ;
- obtenir une première mise au point ;
- valider la résolution astrométrique.

## Étapes réalisées

### 1. Installer et équilibrer le matériel

- monture : `Sky-Watcher EQ6-R Pro` ;
- instrument principal : `C8 EdgeHD + Canon EOS 1200D` ;
- guidage : `EvoGuide 50ED + ASI120MM-S` ;
- équilibrage AD : réalisé ;
- équilibrage DEC : compromis nécessaire à cause du décentrage de la lunette-guide ;
- dégagement du pilier et des câbles : vérifié.

### 2. Connecter les équipements

**Chemin KStars :** `KStars → Outils → Ekos → Profil de l’équipement → Démarrer INDI`

**Chemin INDI :** `Panneau de contrôle INDI → onglet de chaque équipement → Connexion`

- monture : connectée ;
- Canon EOS 1200D : connecté ;
- ZWO ASI120MM-S : connectée ;
- focuser Celestron : connecté ;
- GPS U-Blox : transmis par USB/IP et connecté ;
- joystick Saitek : transmis par USB/IP et connecté.

### 3. Créer les trains optiques

**Chemin KStars :** `KStars → Outils → Ekos → bouton Modifier le train optique`

- train principal : `C8 EdgeHD + Canon 1200D` ;
- monture : `EQMod Mount` ;
- caméra : `Canon DSLR` ;
- focuser : `Celestron SCT Focuser` ;
- focale : `2032 mm` ;
- train de guidage : `EvoGuide 50ED + ASI120MM-S` ;
- caméra de guidage : `ZWO CCD ASI120MM-S`.

### 4. Définir la position de parcage

**Chemin INDI :** `Panneau de contrôle INDI → EQMod Mount → Site Management → Park Options`

- monture placée en position initiale ;
- position actuelle enregistrée comme position de parcage ;
- état `Parked` vérifié avant les autres essais.

### 5. Mettre au point le train de guidage

**Chemin KStars :** `KStars → Outils → Ekos → Mise au point`

- train optique : `EvoGuide 50ED + ASI120MM-S` ;
- réglage mécanique : bague verte de l’EvoGuide ;
- résultat : premières étoiles visibles et exploitables.

### 6. Mettre au point le C8

**Chemin KStars :** `KStars → Outils → Ekos → Mise au point`

- train optique : `C8 EdgeHD + Canon 1200D` ;
- exposition : `4 s` ;
- regroupement : `2×2` ;
- sensibilité : `ISO 1600` ;
- positions testées : `25900`, `25950`, `25955`, `26000` et `26100` ;
- meilleure zone mesurée : de `25950` à `25955` ;
- position retenue : **`25955`** ;
- HFR mesurés à cette position : **`1,97`**, **`2,39`** et **`2,49`**.

### 7. Résoudre le champ par astrométrie

**Chemin KStars :** `KStars → Outils → Ekos → Alignement → Options → Fichiers d’index`

- train optique : `EvoGuide 50ED + ASI120MM-S` ;
- solveur : `StellarSolver` hors ligne ;
- index installés : `4207`, `4208`, `4209` et `4210` ;
- résultat : champ reconnu par StellarSolver.

### 8. Tester l’alignement polaire

**Chemin KStars :** `KStars → Outils → Ekos → Alignement → Alignement polaire`

- erreur polaire initiale : environ `1°` ;
- rotation automatique : trop importante ;
- risque constaté : monture trop proche du pilier ;
- action : procédure interrompue immédiatement ;
- résultat : alignement polaire non terminé.

## RETEX

- **Problème :** le focuser devenait instable lorsqu’il était connecté au hub USB.
  - **Solution :** brancher le focuser directement sur le serveur INDI. [Voir le HowTo](/astronomie/howto/depannage/#focuser-instable-via-le-hub-usb).
- **Problème :** la monture a effectué une rotation trop importante pendant l’alignement polaire.
  - **Solution :** arrêter et parquer immédiatement la monture ; utiliser ensuite des rotations manuelles limitées à 15°.
- **Problème :** StellarSolver ne parvenait pas à résoudre le champ.
  - **Solution :** installer les index `4207` à `4210`. [Voir le HowTo](/astronomie/howto/depannage/#stellarsolver-ne-résout-pas-le-champ).
