## Fiche de session

| Élément | Valeur |
|---|---|
| Nuit | Du 10 au 11 août 2026 |
| Objectif principal | Atteindre Deneb avec la monture |
| Cible | Deneb |
| Instrument principal | C8 EdgeHD + Canon EOS 1200D |
| Guidage | EvoGuide 50ED + ASI120MM-S |
| Logiciels | KStars, Ekos, INDI et StellarSolver |

## Objectif à atteindre

- pointer la monture vers **Deneb** ;
- résoudre l’image par astrométrie ;
- recentrer Deneb avec une erreur inférieure à `10″` ;
- vérifier que le guidage permet une première pose longue.

## Étapes réalisées

### 1. Vérifier le parcage de la monture

**Chemin KStars :** `KStars → Outils → Ekos → Monture`

**Chemin INDI :** `Panneau de contrôle INDI → EQMod Mount → Site Management`

- état vérifié : `Parked` ;
- déclinaison affichée dans INDI : `+90°` ;
- monture laissée parquée pendant les contrôles ;
- dégagement autour du pilier et des câbles vérifié ;
- monture déparquée avant le premier déplacement.

### 2. Vérifier le joystick

**Chemin INDI :** `Panneau de contrôle INDI → EQMod Mount → Motion Control`

- joystick Saitek transmis par USB/IP ;
- fonctionnement vérifié avec `jstest`, puis dans EQMod ;
- vitesse utilisée : de `8×` à `32×` ;
- blocage des mouvements confirmé lorsque la monture est parquée.

### 3. Réaliser l’alignement polaire

**Chemin KStars :** `KStars → Outils → Ekos → Alignement → Alignement polaire`

- train optique : `EvoGuide 50ED + ASI120MM-S` ;
- exposition : `5 s` ;
- regroupement : `1×1` ;
- solveur : `StellarSolver` hors ligne ;
- pointage manuel : activé ;
- rotation AD : `15°`, deux fois dans le même sens ;
- erreur initiale : `1°11′` ;
- erreur finale : **`3′23″`** ;
- erreur en altitude : environ `-3′00″` ;
- erreur en azimut : environ `-1′33″`.

### 4. Pointer Deneb

**Chemin KStars :** `Carte du ciel → rechercher Deneb → clic droit sur Deneb → EQMod Mount → Pointer`

- cible sélectionnée : `Deneb` ;
- déplacement de la monture surveillé jusqu’à son arrêt ;
- dégagement autour du pilier vérifié pendant le déplacement.

### 5. Résoudre et recentrer Deneb

**Chemin KStars :** `KStars → Outils → Ekos → Alignement`

- train optique : `EvoGuide 50ED + ASI120MM-S` ;
- solveur : `StellarSolver` hors ligne ;
- action après résolution : `Pointer vers la cible` ;
- erreur finale de recentrage : **`4″`** ;
- objectif Deneb : **atteint**.

### 6. Calibrer le guidage

**Chemin KStars :** `KStars → Outils → Ekos → Guidage → Options de guidage`

- train optique : `EvoGuide 50ED + ASI120MM-S` ;
- nombre d’itérations : `10` ;
- impulsion de calibration : `1000 ms` ;
- agressivité AD : `0,70` ;
- agressivité DEC : `0,60` ;
- RMS total obtenu : environ **`2,25″`**.

### 7. Prolonger le test sur M27

**Chemin KStars :** `Carte du ciel → rechercher M27 → clic droit sur M27 → EQMod Mount → Pointer`

**Chemin Ekos :** `Ekos → Alignement → sélectionner le train optique → Capturer et résoudre`

- cible secondaire : `M27` ;
- train principal : `C8 EdgeHD + Canon 1200D` ;
- focale : `2032 mm` ;
- erreur de recentrage : environ `8″` ;
- exposition : `60 s` ;
- sensibilité : `ISO 1600` ;
- format : `RAW/FITS` ;
- position du focuser : `25955` ;
- résultat : M27 n’apparaît pas dans le champ du Canon.

## Captures et analyse

### Résolution astrométrique sur M27

![Résolution astrométrique et recentrage sur M27](/assets/images/sessions/2026-08-10/resolution-astrometrique-m27.png)

La capture montre une solution obtenue avec le train **EvoGuide 50ED + ASI120MM-S** :

- coordonnées résolues : AD `20h00m47s`, DEC `22°47′49″` ;
- champ mesuré : `68,2′ × 51,1′` ;
- focale estimée : environ `242 mm` ;
- erreur de recentrage : **8 secondes d’arc**.

**Conclusion RETEX :** le pointage et la résolution fonctionnent correctement sur le train de guidage. Cette capture ne valide toutefois pas l’alignement exact du C8 et du Canon sur le même centre ; une résolution séparée du fichier principal reste nécessaire.

## RETEX

- **Problème :** le guidage affichait un RMS compris entre 16 et 23 secondes d’arc.
  - **Solution :** refaire la calibration avec dix itérations et réduire l’agressivité. [Voir le HowTo](/astronomie/howto/depannage/#guidage-très-instable).
- **Problème :** M27 n’apparaissait pas sur l’image du Canon malgré le recentrage.
  - **Solution :** résoudre le fichier principal avec le train C8 + Canon et l’action `Rien`, sans déplacer la monture.
- **Problème :** Ekos affichait des coordonnées nulles.
  - **Solution :** vérifier l’état de parcage dans le panneau INDI puis déparquer la monture. [Voir le HowTo](/astronomie/howto/depannage/#coordonnées-nulles-dans-ekos).
